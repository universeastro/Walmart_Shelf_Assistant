# Walmart_Shelf_Assistant · 沃尔玛上架助手

按多级表头名称，把**文件 A**（源数据）中的商品信息填入**文件 B**（沃尔玛上架模板），
生成一份新的填充结果，**不覆盖原始模板**。

## 它解决什么问题

沃尔玛上架模板（文件 B）的表头是多级的，很多字段名藏在合并单元格的**二级/三级表头**里，
手工对应列既慢又容易串行——串错一列，到后台就是批量事故。

本工具读取 A 表的字段，按名称匹配到 B 表对应列，把数据写进副本。

## 文件结构

```text
app.py               图形界面（tkinter），选择 A / B / 输出路径
excel_mapper.ps1     实际映射逻辑（PowerShell + Excel COM）
文件/
  A模板.xls          源数据示例
  B模板.xlsx         沃尔玛上架模板
  项目需求文档01.docx  需求说明
README.md
```

## 运行

```powershell
python app.py
```

界面里依次选择文件 A、文件 B 和输出路径，点击「开始填充」。

## 映射规则

1. **优先按字段名称匹配** —— 目标表头会从多级表头中展开后再比对，因此
   「SKU」「Product Name」这类落在二级/三级合并表头上的字段也能被识别。
2. **列字母作为兜底** —— 仅当源字段没有标题时，才回退到按文档中约定的列字母对应。
3. 两轮都匹配不到的字段**不传输**，并在处理记录中列出跳过原因。

## 为什么用 Excel COM 而不是 openpyxl

需求要求 B 表的自带格式不能被破坏（公式、图表、条件格式、数据验证等）。
openpyxl 保存工作簿时会丢弃其中相当一部分，因此这里改为驱动本机真实 Excel
完成写入：先把 B 表复制成输出副本，再在副本上写入，原始模板始终不被修改。

**代价：运行环境必须安装 Microsoft Excel。**
