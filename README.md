# 沃尔玛上架助手

本次写入 B 的映射单元格会设置为“水平对齐：填充”。表头及未写入单元格不应用此设置。

导出范围由用户选择：默认“仅可见行”，跳过筛选隐藏及手动隐藏的行；选择“全部数据行”则包含隐藏行。两种模式均按原顺序在 B 中连续排列，完全没有映射数据的空行仍跳过。请先在 Excel/WPS 中保存筛选或隐藏状态，再导入文件。处理记录会显示本次模式及跳过的隐藏行数。命令行通过 `-RowMode Visible` 或 `-RowMode All` 选择。

这是一个基于 Microsoft Excel 自动化的桌面工具，用于把文件 A 的商品信息填入文件 B 的沃尔玛上架模板。

## 运行环境

- Windows
- Microsoft Excel（用于读取 `.xls`、`.xlsx` 并保留模板格式）
- Python 3.10 或更高版本

## 启动

在本目录运行：

```powershell
python app.py
```

在窗口中选择：

1. 文件 A：源商品数据。
2. 文件 B：沃尔玛模板。
3. 输出文件：新的 `.xlsx` 文件路径。

APP 会在开始处理或关闭窗口时保存这三个路径，下次启动自动恢复，无需重新浏览。可直接编辑路径或点击“浏览...”更换文件；清空路径后关闭也会记住空值。配置保存在当前用户的 `%LOCALAPPDATA%\WalmartShelfAssistant\settings.json`，不会修改源文件或模板。启动时若文件 A 或 B 已移动、删除或无法访问，会自动清空对应路径，请重新浏览选择；输出路径保留，即使输出文件尚未生成。

程序会选择 B 中包含多级表头的商品内容工作表，使用叶子字段名称匹配目标列，并将 A 的数据值写入目标数据行。原始文件不会被覆盖。

## 当前模板的实际映射

当前随项目提供的 B 模板只有两个附加图片字段和三个 Key Features 字段，因此不存在的目标字段会记录为“跳过”，不会写入相邻字段。

源字段标题匹配优先。对于 A 模板中没有标题的 `E` 列，按需求文档使用 `E -> Variant Group ID` 的列号兜底。
