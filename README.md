# 沃尔玛上架助手

应用提供两个互相独立的映射方案：

- **主线 01**：使用 `文件/01/` 的沃尔玛上架模板和多级表头映射。
- **支线 02**：使用 `文件/02/`，将 A 的 `SKU`、`自定义` 分别写入 B 的 `SKU`、`平台SKU`；A 的该字段也兼容真实业务文件中的表头名 `自定义SKU`。

主线和支线不得混用映射规则。切换方案时，界面会切换到该方案的独立文件页面，并恢复它上次使用的 A、B、输出路径。选择到可明确识别为另一方案的目标文件时，程序会先询问是否切换页面。

主线 B 中已有商品数据时，保留所有旧记录，从最后一条记录下方留出 3 行后追加（例如末行 20，新批次从 24 行开始）。空模板仍从正常数据起始行写入。最后记录按数据区所有已使用列的固定值识别，包含隐藏行，不回填旧记录间的空隙；仅有格式或预置公式不作为商品记录。公式单独保护：若新批次的映射单元格包含公式或合并单元格，停止并提示，不覆盖。间隔行不清空、不插入整行，以免改变原有公式和规则。

支线默认保留 B 的既有记录，并从最后一条记录下方留出 3 行后追加；空目标从第 2 行写入。确需覆盖旧数据时，可直接调用映射脚本并显式传入 `-WriteMode Replace`。原始 B 文件始终不修改。

新批次内部仍保持同行字段关联、固定列映射及所选导出范围的原顺序；不去重，不更新旧商品。原始 B 不修改，结果另存为输出副本。处理记录显示本批次的起始行。

本次写入 B 的映射单元格中，仅 Color 字段设为“水平对齐：左对齐”，其他映射字段保持“水平对齐：填充”。按表头名称识别 Color，不依赖固定列号。表头、已有数据及未写入单元格不应用此设置。

导出范围由用户选择：默认“仅可见行”，跳过筛选隐藏及手动隐藏的行；选择“全部数据行”则包含隐藏行。两种模式均按原顺序在 B 中连续排列，完全没有映射数据的空行仍跳过。请先在 Excel/WPS 中保存筛选或隐藏状态，再导入文件。处理记录会显示本次模式及跳过的隐藏行数。命令行通过 `-RowMode Visible` 或 `-RowMode All` 选择。

这是一个基于 Microsoft Excel 自动化的桌面工具，用于把文件 A 的商品信息填入文件 B 的沃尔玛上架模板。

界面采用浅色工作台布局，处理记录支持滚动查看。填充期间显示动态进度指示（不代表完成百分比），并暂时锁定文件路径与导出范围；完成或失败后恢复操作。

路径输入框不再显示悬浮提示，路径编辑、浏览和记忆功能不变；浏览窗口优先打开原路径所在目录。处理后显示读取、写入及跳过隐藏行的摘要，日志附带时间；成功后可点击“打开输出位置”查看实际生成文件所在文件夹，此按钮不受之后编辑输出路径影响。

## 运行环境

直接运行源码时需要：

- Windows
- Microsoft Excel（用于读取 `.xls`、`.xlsx` 并保留模板格式）
- Python 3.10 或更高版本

源码运行需要先安装拖放依赖：

```powershell
py -m pip install -r requirements.txt
```

若未安装该可选依赖，应用仍可启动并通过“浏览...”选择文件，但文件拖放不可用。

使用下面的打包版本时，目标电脑**只需 Microsoft Excel**，不必安装 Python。

## 启动

在本目录运行：

```powershell
python app.py
```

在窗口中选择：

1. 文件 A：源商品数据。
2. 文件 B：目标文件。
3. 输出文件：新的 `.xlsx` 文件路径。
4. 映射方案：主线选择“主线 01”，支线选择“支线 02”。

文件 A、文件 B 和输出文件均可拖到对应路径框；每次只接受一个 `.xls`、`.xlsx` 或 `.xlsm` 文件。

APP 会分别保存主线和支线页面的三条路径以及最后使用的方案，下次启动自动恢复，无需来回重新浏览。可直接编辑路径或点击“浏览...”更换文件；清空路径后关闭也会记住空值。旧版单组路径配置会在首次启动时自动迁移。配置保存在当前用户的 `%LOCALAPPDATA%\WalmartShelfAssistant\settings.json`，不会修改源文件或模板。启动时若某个方案的文件 A 或 B 已移动、删除或无法访问，只会清空该方案对应的无效路径；输出路径仍会保留，即使输出文件尚未生成。

输出文件已经存在时，点击“开始填充”会显示“替换文件”“继续写入”“取消”三个明确选项。替换表示以文件 B 重新生成并覆盖现有输出；继续写入表示保留现有输出，并在最后一条数据后留 3 行追加。选择输出文件时不再由系统保存窗口提前询问覆盖，以免把“替换文件”和“继续写入”混为一谈。

主线会选择 B 中包含多级表头的商品内容工作表；支线会选择同时包含 `SKU` 和 `平台SKU` 的工作表。两者均按字段名称匹配目标列并只写值，原始文件不会被覆盖。

## 打包与迁移到其他电脑

打包成免安装版本，拷到其他 Windows 电脑上双击即可运行：

```powershell
py -m pip install -r requirements-build.txt
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

产物是 `dist\WalmartShelfAssistant\` 整个文件夹（约 26 MB）。**把这个文件夹整体拷贝过去**，双击其中的 `WalmartShelfAssistant.exe` 即可。

要在**本机**装好并生成桌面快捷方式：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1
```

程序装到 `%LOCALAPPDATA%\Programs\WalmartShelfAssistant\`（免管理员权限），桌面生成「沃尔玛上架助手」快捷方式。卸载就是删掉该目录和桌面快捷方式。

注意 `install.ps1` 是**复制**而非链接到 `dist\`：`build.ps1` 每次会删除重建 `dist\`，快捷方式若指向那里，下次打包就失效了。

目标电脑**必须安装 Microsoft Excel**——映射通过 Excel COM 自动化完成（需求第 15 条要求保留模板格式，这一步无法用其他库替代）。除此之外无需任何安装：Python 已打进包里，PowerShell 是 Windows 自带的。

三点说明：

- 路径配置保存在**目标电脑自己**的 `%LOCALAPPDATA%\WalmartShelfAssistant\` 下，不随文件夹迁移，首次运行需重新选择 A/B 文件。
- 打包出的 exe 未做代码签名，首次在别的电脑上运行会被 Windows SmartScreen 拦截，选择“更多信息”→“仍要运行”即可。
- `excel_mapper.ps1` 以明文形式放在 `_internal\` 里。若要调整映射规则，可直接编辑该文件，无需重新打包。

## 主线模板的实际映射

当前随项目提供的 B 模板只有两个附加图片字段和三个 Key Features 字段，因此不存在的目标字段会记录为“跳过”，不会写入相邻字段。

源字段标题匹配优先。对于 A 模板中没有标题的 `E` 列，按需求文档使用 `E -> Variant Group ID` 的列号兜底。
